# Calendar MVP

Сервис записи на встречи: владелец публикует публичную страницу записи с настройками доступности, гость выбирает тип встречи и свободный слот и бронирует время. Учебное демо без аутентификации; система не связана с внешними календарями.

## Language

### Участники

**Owner**:
Владелец календаря: публикует страницу записи и настраивает свою доступность. Идентифицируется публичным uuid, не связанным с PII. Может быть активным или неактивным; активные владельцы показываются в публичном списке.
_Избегать_: Пользователь, аккаунт, профиль, владелец страницы

**Guest**:
Пользователь, который бронирует слот. Идентифицируется уникальным email. Гость не становится владельцем автоматически.
_Избегать_: Посетитель, клиент, участник, покупатель

**Default owner**:
Владелец, к которому привязан личный кабинет (админка) через конфигурацию; в MVP это seed-владелец. Это привязка офиса к существующему владельцу, а не отдельная роль.
_Избегать_: Администратор, админ, владелец по умолчанию

### Расписание владельца

**Calendar**:
Публичная страница записи владельца с его настройками доступности. Отдельной сущности нет — это проекция владельца. Интеграции с внешними календарями (Google/Apple) вне скоупа.
_Избегать_: Календарь Google/Apple, календарная сетка, настройки календаря

**Availability settings**:
Настройки доступности владельца: начало и конец рабочего дня, часовой пояс и рабочие дни недели. Все времена хранятся в UTC, а отображаются в часовом поясе владельца.
_Избегать_: Настройки календаря, настройки владельца, профиль

**Booking window**:
Окно бронирования — 14 дней начиная с текущей даты включительно. За его пределами слоты не генерируются и бронирование недоступно.
_Избегать_: Диапазон, период, окно слотов

### Бронирование

**Event**:
Тип встречи владельца: название, описание и длительность. Название уникально в рамках одного владельца. Event — шаблон встречи; конкретная запись по нему — Booking.
_Избегать_: Встреча, событие, тип события

**Slot**:
Свободный временной интервал для бронирования, вычисляемый из рабочих часов и длительности события. Имеет статус available или unavailable (причина: booked, past). Не хранится в базе.
_Избегать_: Таймслот, окно, интервал, встреча

**Booking**:
Бронирование: конкретная встреча гостя у владельца по типу встречи (Event) в конкретном слоте. Два бронирования не могут пересекаться во времени.
_Избегать_: Запись, бронь, appointment, reservation
