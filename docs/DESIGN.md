# Design System — стиль Cal.com

Дизайн-система фронтенда MVP «Запись на звонок» в стиле Cal.com. Применяется к SPA в `web/` (Фаза 6).

---

## 1. Принципы

- **Монохромность.** Cal.com — почти чёрно-белый бренд: основа — градации серого, цвет используется сдержанно, только для акцентов и статусов.
- **Типографика.** Заголовки — Cal Sans (weight 600, негативный трекинг), весь остальной текст — Inter.
- **Темы.** Светлая по умолчанию для публичных страниц; тёмная — для админской панели.
- **Бренд.** Используется нейтральный бренд «Calendar MVP». Логотип и слово Cal.com не используются.

---

## 2. Палитра (токены)

### Светлая тема (`:root`)

| Токен | HEX | Применение |
|-------|-----|------------|
| `--color-ink` | `#111111` | Заголовки, первичные CTA |
| `--color-body` | `#374151` | Основной текст |
| `--color-muted` | `#6b7280` | Вторичный текст |
| `--color-hairline` | `#e5e7eb` | Границы, разделители таблиц |
| `--color-hairline-soft` | `#f3f4f6` | Мягкие разделители секций |
| `--color-canvas` | `#ffffff` | Фон страницы |
| `--color-surface-soft` | `#f8f9fa` | Фон секций, навигация |
| `--color-surface-card` | `#f5f5f5` | Фон карточек, бейджей |
| `--color-success` | `#10b981` | Статус успеха |
| `--color-warning` | `#f59e0b` | Предупреждения |
| `--color-error` | `#ef4444` | Ошибки валидации |

### Тёмная тема (`.theme-dark`, админка)

| Токен | HEX | Применение |
|-------|-----|------------|
| `--color-surface-dark` | `#101010` | Фон страницы |
| `--color-surface-dark-elevated` | `#1a1a1a` | Карточки, таблицы |
| `--color-on-dark` | `#ffffff` | Основной текст |

Статусные цвета `success`/`warning`/`error` переопределяются в тёмной теме на более светлые оттенки для контраста.

---

## 3. Типографика

- **Заголовки:** Cal Sans, weight 600, негативный трекинг (`letter-spacing` от −2px до −0.5px в зависимости от размера).
- **Текст:** Inter, 14–16px, line-height 1.5.
- **Шрифты** подключаются локально из `web/fonts/` (Cal Sans и Inter, лицензия OFL) через `@font-face` с `font-display: swap`. CDN не используется — проект самодостаточен.

| Стиль | Шрифт | Размер | Вес | Трекинг | Применение |
|-------|-------|--------|-----|---------|------------|
| Title 1 | Cal Sans | 28px | 600 | −1px | Заголовок страницы |
| Title 2 | Cal Sans | 24px | 600 | −0.75px | Заголовок секции |
| Title 3 | Cal Sans | 20px | 600 | −0.5px | Подзаголовок, имя владельца |
| Body md | Inter | 16px | 400 | 0 | Основной текст |
| Body sm | Inter | 14px | 400 | 0 | Вторичный текст |
| Caption | Inter | 12px | 500 | 0 | Метки, подписи |
| Button | Inter | 14px | 600 | 0 | Кнопки |

## 4. Компоненты

Список стилевых классов, применяемых к экранам из `docs/PRD.md` §9.

### 4.1. Кнопки

| Класс | Стиль | Применение |
|-------|-------|------------|
| `.btn` | Базовые отступы, радиус, weight 600 | Основа всех кнопок |
| `.btn--primary` | Фон `--color-ink`, текст белый; hover — `#242424` | «Забронировать время», «Добавить», «Подтвердить» |
| `.btn--secondary` | Прозрачный, граница `--color-hairline` | «Назад», «Создать свой календарь» |
| `.btn--disabled` | Фон `--color-hairline`, текст muted, `cursor: not-allowed` | Недоступные действия |

### 4.2. Карточки

- `.card` — белый/тёмный фон, граница `--color-hairline`, скругление, мягкая тень.
- `.card--owner` — карточка владельца в списке `/owners`: имя + кнопка «Записаться на встречу», кликабельна целиком.
- `.card--event` — карточка события в Шаге 2 визарда: название, описание, длительность; hover-подсветка, кликабельна.
  - Бейдж длительности в правом верхнем углу карточки (например, «15м», «30м») — caption-стиль на фоне `--color-surface-card`.

### 4.3. Резюме брони (Шаг 4)

- `.booking-summary` — липкая панель слева от формы гостя (паттерн Cal.com).
- Список label-value: «Что» (событие и длительность), «Когда» (дата и время в tz владельца), «Пояс» (часовой пояс).
- Лейблы — caption-стиль (`--color-muted`), значения — body-стиль (`--color-ink`).

### 4.4. Таблицы (админка)

- `.table` — границы ячеек `--color-hairline`, шапка полужирная, зебра `--color-surface-soft` через строку.
- Столбцы бронирований: дата и время, событие, гость, email.
- Столбцы событий: ID (UUID), название, длительность, активность.

### 4.5. Формы

- `.field` — контейнер поля с подписью (`label`, caption-стиль).
- `.input` — граница `--color-hairline`, фокус — `--color-ink`, радиус.
- `.field--error` — граница и текст `--color-error`; сообщение об ошибке caption-стилем.
- Валидация email — стандартная HTML5 (`type="email"`).

### 4.6. Статусные бейджи слотов

- `.slot` — кнопка-слот в списке времени Шага 3.
- `.slot--available` — `available`: акцентный (выделен цветом), кликабельный.
- `.slot--unavailable` — `unavailable`: серый (`--color-muted`), `disabled`.
  - `reason: "booked"` — метка «забронировано».
  - `reason: "past"` — метка «недоступно».
- `.slots-count` — строка доступности над слот-листом (например, «Доступно: 6 слотов») — caption-стиль, `--color-muted`.

### 4.7. Календарная сетка (Шаг 3)

- `.calendar` — сетка 7 дней на неделю; заголовок месяца — Title 2.
- `.calendar__day--weekend` и `.calendar__day--disabled` — неактивные дни (серые).
- `.calendar__day--selected` — выбранный день, акцентная подсветка.
- Дни без доступных слотов и вне 14-дневного окна — неактивные.

### 4.8. Прогресс-индикатор визарда

- `.steps` — индикатор «1 — 2 — 3 — 4 — 5» вверху Шагов 2–5.
- Текущий шаг — акцентный (`--color-ink`), пройденные — muted, будущие — hairline.

### 4.9. Навигация

- `.topbar` — верхняя панель: бренд «Calendar MVP» слева, действия справа (например, «Создать свой календарь»).
- `.link-back` — «← Назад к списку».

### 4.10. Пустые состояния

- `.empty` — центрированный muted-текст: «Пока нет доступных календарей», «Нет предстоящих бронирований».

## 5. Форматы дат и времени

Все времена показываются на фронтенде в часовом поясе владельца (RU-локализация), даже если это не совпадает с поясом пользователя.

| Контекст | Пример | Примечание |
|----------|--------|------------|
| Дата (полная) | «пятница, 7 августа 2026 г.» | `toLocaleDateString('ru-RU', { weekday: 'long', day: 'numeric', month: 'long', year: 'numeric' })` |
| Время в слоте | «09:40–09:50» | Интервал слотов, локальное время владельца |
| Дата и время в деталях | «9:40 AM – 9:50 AM (Москва, стандартное время)» | С поясом в скобках |
| Пояс в резюме | «Europe/Moscow» | Название IANA-таймзоны |

---

## 6. Применение тем

- Светлая тема — по умолчанию (`:root`): `/`, `/owners`, `/owners/{uuid}` (визард), `/owners/new`.
- Тёмная тема — класс `.theme-dark` на корневом элементе личного кабинета владельца `/office`.
- Токены переопределяются через CSS custom properties; компоненты используют только переменные.
